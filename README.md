# 脆皮红警玩法（由 AI 制作）

> 把所有单位、建筑、树木、桥梁的血量全部改成 **5** —— 一枪一栋楼，一个油桶炸穿半个基地。
> 本仓库**不包含任何游戏本体文件**，只提供规则文件、一键应用脚本与技术文档。请自备正版游戏。

---

## 这个玩法是什么

| 项目 | 原版 | 脆皮模式 |
|---|---|---|
| 步兵 / 载具 / 飞机 / 建筑血量 | 75 ~ 3000 | **5** |
| 树木 / 桥梁 | 200 / 1500 | **5** |
| 结果 | 需要反复交火 | **任何一次攻击都能摧毁目标** |

核心乐趣在**连锁反应**：一个油桶被流弹打中 → 4 格内建筑全灭 → 其中有的建筑自带死亡武器（油井 600 伤害、核电站直接殉爆）→ 再炸一轮。配合 5 点血量，一次交火就能把 AI 的整个基地连锁拆掉。

### 刻意保留的两个例外

| 位置 | 血量 | 原因 |
|---|---|---|
| 苏军第二关 · 气垫船 `[SAPC]` | 800 | 任务原本的强化值，否则运兵船一碰就沉，关卡没法打 |
| 盟军第一关 · 自由女神像 `[CANEWY04]` | 10000 | 任务原本的强化值，是必须守住的目标 |

## 安装

### 方式一：一键脚本（推荐）

```bash
python apply_crispy_mod.py "D:\RAY2\红色警戒2 完整版"
```

脚本会：
1. 把要改的文件先备份到游戏目录下的 `_crispy_backup\`
2. 覆盖 `rules.ini`
3. 修改 11 个任务包/地图里**地图自带的血量覆盖**（等长字节替换，不破坏数据包索引）
4. 给 `game.exe` 打一个 6 字节补丁，修掉 5 血模式触发的引擎除零崩溃
5. 打印完整报告

撤销（从备份还原）：

```bash
python apply_crispy_mod.py "D:\RAY2\红色警戒2 完整版" --undo
```

参数：
- `--all-five`：连上面两个任务例外也一起改成 5（默认保留例外）
- `--no-exe`：跳过 exe 补丁（不推荐，会崩）

### 方式二：手动

1. 把 `rules.ini` 覆盖进游戏目录
2. 用脚本改任务包（第 3 步），或直接用仓库里的脚本
3. exe 补丁：见下方「技术细节」

> **改完必须完全退出游戏再重开**，规则是启动时读的。

## 技术细节：为什么还需要给 exe 打补丁

血量改成 5 之后，游戏会在**维修费用计算**处崩溃（`EXCEPTION_INT_DIVIDE_BY_ZERO`）。原因是引擎里这段代码：

```
维修费 = max(1, ( 造价 / ( 血量上限 / RepairStep ) ) × RepairPercent )
                          └──── 整数除法，会截断 ────┘
```

- 原版血量 125 ~ 1000，`RepairStep = 8` → 商 ≥ 15，永远安全
- 血量改成 5 后 → `5 / 8 = 0` → 第二步拿这个 0 当除数 → **崩溃**

触发场合：AI 自动维修受损建筑、玩家点维修、维修厂修单位。所以遭遇战几分钟内必崩，而战役里没碰修复逻辑就能过关。

**两层修复：**

| 层 | 做法 | 说明 |
|---|---|---|
| 1 | `rules.ini` 里 `RepairStep=1`、`IRepairStep=1` | 让 `5 / 1 = 5`，不再截断成 0 |
| 2 | `game.exe` 偏移 `0x2DAEDC` 处 6 字节补丁 | `F7 B9 34 13 00 00`（`idiv [ecx+0x1334]`）→ `B8 05 00 00 00 90`（`mov eax,5` + `nop`），让商恒为 5，彻底堵死这条路 |

另外还有 7 个「在类型表里被声明、但段落缺失或被注释」的类型（`DeathDummy` / `APACHE` / `NAWAST` / `GARADR` / `NAHPAD` / `CAEURO01` / `CAIRSFGL`），它们血量默认是 0，同样会触发除零 —— `rules.ini` 里已给它们补上 `Strength=5`。

详细的反汇编分析过程见 [`docs/崩溃原理分析.md`](docs/崩溃原理分析.md)。

## 兼容性

| 项目 | 情况 |
|---|---|
| 原版红警2 1.006（`game.exe`） | ✅ 适用 |
| 尤里的复仇（`gamemd.exe`） | ❌ 不适用，它读的是 `rulesmd.ini`，规则结构也不同 |
| 其他版本 / 其他整合版 | ⚠️ 任务包里的覆盖内容可能不一样，脚本会打印它改了什么，请自行核对 |

exe 补丁会在动手前**校验目标字节**，版本不符会直接拒改，不会把程序改坏。
